# Task 4：思考题

## 1. Make 和简单的 build.sh 有什么区别？

build按顺序一条一条执行命令，无论文件是否被改动过，每次都运行全部命令。它适合小项目，文件少的情况。
Make会检查目标文件和依赖文件的修改时间戳，若依赖文件没改动，目标文件比它新，则不执行编译命令，直接提示up to date，如果改了才执行gcc。

## 2. CMake 是编译器吗？

执行 `cmake --build build` 时，最终是谁在编译 C 源文件？

CMake不是编译器，它是构建系统生成器。
最终是gcc将.c编译生成.o目标文件。

## 3. 为什么不希望每次都重新编译所有 `.c` 文件？

绝大多数的49个文件没有改动，全部重新编译会很慢，经过预处理、词法分析、语法分析、生成汇编和汇编成目标文件的过程，浪费时间、CPU还有内存等等。
