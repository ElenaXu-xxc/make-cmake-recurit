# Task 1：从 C 源码到可执行文件

请用自己的语言简要说明下面几个阶段分别做了什么：

1. 预处理
2. 编译
3. 汇编
4. 链接

建议控制在 300～500 字，不需要展开复杂细节。
# Task 1：从 C 源码到可执行文件
1. **预处理**：读取C源文件，处理以`#`开头的指令。展开`#include`头文件内容，完成宏替换，删除注释，处理条件编译，输出预处理后的`.i`文本文件。这一步不做语法检查，只做文本替换。
-输入`gcc -E hello.c -o hello.i`后，生成了`hello.i`

2. **编译**：读取预处理后的文件，进行词法、语法、语义检查，将C语言代码翻译成对应的汇编指令，生成`.s`汇编文本文件。如果代码有语法错误，会在这个阶段报错终止。
-输入`gcc -S hello.i -o hello.s`后，生成了`hello.s`

3. **汇编**：读取汇编代码，把汇编指令翻译成机器码，生成二进制的`.o`目标文件。目标文件包含机器指令，但里面引用的外部函数（如printf）地址还没有确定，不能直接运行。
-输入`gcc -c hello.s -o hello.o`后，生成了`hello.o`

4. **链接**：将一个或多个`.o`目标文件，连同系统提供的库文件合并。解析各个文件之间的函数、符号引用，补齐缺失的函数地址，最终生成完整、可直接运行的可执行程序。
-输入`gcc hello.o -o hello`后，生成了`hello.exe`
